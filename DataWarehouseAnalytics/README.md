# Data Warehouse Analytics 

### A SQL Server Project Focused on Structured Data Exploration

## 📌 Overview

DataWarehouseAnalytics is a SQL Server project designed to explore and analyze data through a well-structured approach.

-> This project includes:

-> A single SQL script that:

-> Creates the database

-> Creates the schema (gold)

-> Creates all tables

-> Loads the dataset

-> Performs detailed data exploration across six analytical areas

-> Datasets used for loading data into the tables

##### The goal is to help understand the dataset and build strong SQL exploration and analysis skills.

## 🏗️ Database Structure

The SQL script builds the following tables under the gold schema:

#### gold.dim_customers

Customer demographics and identification details.

##### gold.dim_products

Product information including category, cost, and product line.

##### gold.fact_sales

Sales transaction data linking customers and products.

## 📊 Data Exploration Sections

The SQL file contains structured exploratory analysis divided into six major sections:

#### 1. Database Exploration

#### 2. Dimension Exploration

#### 3. Date Exploration

#### 4. Measure Exploration

#### 5. Magnitude Exploration

#### 6. Ranking Exploration
